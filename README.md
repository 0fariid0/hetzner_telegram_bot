# 🤖 ربات مدیریت Hetzner در تلگرام

نسخه‌ی سبک و فارسی برای مدیریت سرورهای **Hetzner Cloud** از طریق تلگرام؛ با تمرکز کامل روی مدیریت حساب و سرورهای Hetzner.

## 🚀 نصب یک‌دستوری

روی Ubuntu/Debian دستور زیر را اجرا کنید:

```bash
bash <(curl -Ls --ipv4 https://raw.githubusercontent.com/0fariid0/hetzner_telegram_bot/main/setup.sh)
```

اسکریپت نصب به‌صورت خودکار Python و محیط مجازی را آماده می‌کند، ربات را دانلود می‌کند، توکن‌ها را از شما می‌گیرد و سرویس `systemd` را فعال می‌کند.

> **نکته:** این دستور بعد از آپلود همین سورس در ریپوی `0fariid0/hetzner_telegram_bot` با شاخه `main` آماده‌ی استفاده است. اگر نام ریپو را عوض کردید، آدرس دستور نصب و مقادیر `REPO_OWNER`/`REPO_NAME` در `setup.sh` را هم تغییر دهید.

## ✨ امکانات فعلی

- 🖥 نمایش همه سرورهای Hetzner
- 🟢 روشن کردن سرور
- 🔴 خاموش کردن امن سرور
- 📊 نمایش وضعیت، IPv4، نوع سرور و موقعیت
- 🌐 نمایش تعداد IPv4های آزاد
- ➕ اتصال Primary IPv4 آزاد به سرور
- 🗑 جدا کردن و حذف IPv4 با تأیید نهایی
- 🔄 بروزرسانی سریع اطلاعات سرور
- 🔐 محدود کردن دسترسی به یک شناسه کاربر یا گروه تلگرام
- 🇮🇷 رابط کاربری تلگرام کاملاً فارسی

## 🔑 چیزهایی که برای نصب لازم است

1. **Telegram Bot Token** از BotFather
2. **Hetzner Cloud API Token** با دسترسی Read/Write
3. **Telegram Chat/User ID** مجاز

برای دیدن شناسه‌ی همان گفت‌وگو می‌توانید بعد از اجرای ربات دستور `/id` را بفرستید. اگر هنگام نصب شناسه را خالی بگذارید، بخش مدیریت قفل می‌ماند تا مقدار `ALLOWED_CHAT_ID` را در `/opt/hetzner-telegram-bot/.env` تنظیم و سرویس را ریستارت کنید.

## 🧭 دستورات تلگرام

| دستور | کاربرد |
|---|---|
| `/start` | منوی اصلی |
| `/servers` | نمایش و مدیریت سرورها |
| `/help` | راهنما |
| `/id` | نمایش شناسه گفتگو |

## 🛠 مدیریت سرویس

```bash
systemctl status hetznerbot
systemctl restart hetznerbot
systemctl stop hetznerbot
systemctl start hetznerbot
journalctl -u hetznerbot -f
```

## 📂 ساختار پروژه

پروژه عمداً مینیمال نگه داشته شده است:

```text
hetzner_telegram_bot/
├── bot.py
├── setup.sh
├── README.md
└── .gitignore
```

فایل `.env` هنگام نصب روی سرور ساخته می‌شود و داخل Git قرار نمی‌گیرد.

## ⚠️ نکته درباره Primary IPv4

Hetzner برای اتصال یا جدا کردن Primary IP از سرور محدودیت دارد و این عملیات باید روی سرور خاموش انجام شود. ربات قبل از انجام این عملیات وضعیت سرور را بررسی می‌کند. حذف IPv4 نیز فقط بعد از تأیید نهایی کاربر انجام می‌شود.

## 🔒 امنیت

- توکن‌ها داخل فایل `.env` روی سرور ذخیره می‌شوند و در سورس Git قرار نمی‌گیرند.
- دسترسی مدیریتی فقط برای `ALLOWED_CHAT_ID` فعال است.
- فایل تنظیمات هنگام نصب با سطح دسترسی محدود ساخته می‌شود.
- توکن Hetzner و Telegram را داخل پیام، Issue یا ریپوی عمومی منتشر نکنید.
