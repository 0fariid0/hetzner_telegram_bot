# 🤖 ربات خصوصی مدیریت Hetzner در تلگرام

یک پنل سبک، فارسی و خصوصی برای مدیریت چند پروژه **Hetzner Cloud** از داخل تلگرام. Cloudflare به‌طور کامل حذف شده و رابط ربات بر پایه یک **پنل تک‌پیامی** طراحی شده است تا چت شلوغ نشود.

## 🚀 اجرا / نصب / آپدیت با یک دستور

روی Ubuntu/Debian اجرا کنید:

```bash
bash <(curl -fsSL --ipv4 https://raw.githubusercontent.com/0fariid0/hetzner_telegram_bot/main/setup.sh)
```

این دستور **مستقیماً نصب را شروع نمی‌کند**؛ ابتدا منوی مدیریتی Installer باز می‌شود و خودتان Install، Update، Token Management یا Service Management را انتخاب می‌کنید. ورودی‌های منو مستقیماً از ترمینال (`/dev/tty`) خوانده می‌شوند تا اجرای یک‌خطی هم همیشه تعاملی بماند.

بعد از اجرای دستور، منوی انگلیسی زیر باز می‌شود:

```text
1) Install
2) Update
3) Token Management
4) Service Management
0) Exit
```

بنابراین برای آپدیت یا تغییر توکن‌ها لازم نیست فایل `.env` را دستی ویرایش کنید.


بعد از انتخاب پروژه:

- نام و تعداد سرورها داخل همان پیام نمایش داده می‌شود.
- وضعیت، پلن، IPv4 و ترافیک هر سرور به‌صورت خلاصه در متن دیده می‌شود.
- زیر همان پیام برای هر سرور دکمه شیشه‌ای وجود دارد.
- با انتخاب یک سرور، همان پیام به صفحه مدیریت آن سرور تبدیل می‌شود.
- در تمام مراحل دکمه **برگشت** وجود دارد.

- Refresh، Resize، Floating IP و برگشت همگی با ویرایش همان پیام انجام می‌شوند.

> فقط هنگام واردکردن نام Floating IP یا نام سرور جدید لازم است یک پیام متنی بفرستید. ربات بعد از دریافت نام تلاش می‌کند همان پیام ورودی را پاک کند و پنل اصلی را در همان پیام قبلی بروزرسانی کند.

## ➕ ساخت و حذف سرور

از داشبورد هر پروژه گزینه **ساخت سرور** اضافه شده است. روند ساخت ساده است:

1. نام سرور را به‌صورت پیام می‌فرستید.
2. Location را با دکمه شیشه‌ای انتخاب می‌کنید.
3. فقط پلن‌هایی که Hetzner در همان لحظه برای آن Location `Available` گزارش می‌کند نمایش داده می‌شوند.
4. پلن را با دکمه انتخاب می‌کنید.
5. انتخاب می‌کنید IPv6 فعال باشد یا نه؛ IPv4 همیشه فعال است.
6. روش ورود را انتخاب می‌کنید: **SSH Key** یا **رمز root**.
7. اگر SSH Key را انتخاب کنید، کلیدهای ثبت‌شده همان پروژه Hetzner با دکمه شیشه‌ای نمایش داده می‌شوند و کلید موردنظر را انتخاب می‌کنید.
8. ربات جدیدترین Ubuntu موجود و سازگار با معماری پلن را انتخاب می‌کند.
9. صفحه تأیید، روش ورود انتخاب‌شده را نیز نشان می‌دهد و سپس سرور ساخته و روشن می‌شود.

اگر حالت **رمز root** انتخاب شود، سرور بدون SSH Key ساخته می‌شود و رمز `root` برگشتی Hetzner فقط بعد از ساخت در همان پنل نمایش داده می‌شود. در حالت **SSH Key**، کلید انتخاب‌شده هنگام ساخت داخل سرور Inject می‌شود.

برای حذف نیز داخل صفحه سرور دکمه **حذف سرور** وجود دارد و قبل از حذف، تأیید نهایی گرفته می‌شود. حذف سرور و داده‌های دیسک قابل بازگشت نیست.

## 💸 مانیتور موجودی Cost-Optimized

ربات به‌صورت پیش‌فرض هر **۱ ساعت** موجودی پلن‌های ارزان Cost-Optimized را از API Hetzner بررسی می‌کند. خانواده‌های فعلی `CX` و `CAX` پوشش داده می‌شوند.

وقتی یک پلن/Location که قبلاً موجود نبود Available شود، ربات یک اعلان می‌فرستد و در آن **تمام پلن‌های Cost-Optimized موجود را به تفکیک Location** لیست می‌کند. تا وقتی موجودی تغییر نکند پیام تکراری ارسال نمی‌شود؛ اگر موجودی تمام شود و بعداً دوباره برگردد، مجدداً هشدار داده می‌شود.

بررسی دستی از منوی اصلی با گزینه **موجودی Cost-Optimized** در دسترس است. داخل همان صفحه می‌توانید مانیتور خودکار را با دکمه شیشه‌ای **روشن یا خاموش** کنید؛ وضعیت انتخاب‌شده بعد از ری‌استارت نیز حفظ می‌شود.

> فیلد Availability در API Hetzner شاخص لحظه‌ای است و تضمین قطعی Allocation نیست؛ ممکن است بین نمایش Available و مرحله نهایی ساخت ظرفیت تمام شود.

پیش‌فرض فاصله بررسی:

```env
CHEAP_CHECK_HOURS=1
```

## 🔁 تعویض خودکار Primary IPv4

در صفحه هر سرور دکمه **تعویض Primary IPv4** وجود دارد.

می‌توانید یکی از IPv4های آزاد همان Location را انتخاب کنید یا از ربات بخواهید یک IPv4 جدید بسازد. روند تعویض به‌صورت خودکار انجام می‌شود:

1. ارسال Shutdown امن به سرور
2. انتظار تا وضعیت سرور در Hetzner به `off` برسد
3. Unassign کردن Primary IPv4 فعلی
4. Assign کردن IPv4 جدید
5. روشن کردن دوباره سرور و انتظار برای `running`

Primary IPv4 قبلی **حذف نمی‌شود** و بعد از تعویض به حالت آزاد در پروژه باقی می‌ماند. از بخش `Primary IPv4` در داشبورد پروژه می‌توانید تمام IPv4های موجود را ببینید و IPهای آزاد را با تأیید نهایی حذف کنید.

اگر اتصال IP جدید در میانه عملیات خطا بدهد، ربات تلاش می‌کند IP قبلی را دوباره به سرور متصل کند و سرور را روشن کند.

> Hetzner برای Assign/Unassign کردن Primary IP روی سرور موجود، نیاز دارد وضعیت سرور `off` باشد.

## ⚙️ Resize

از صفحه هر سرور گزینه **تغییر سایز** در دسترس است.

- وضعیت Available بودن **پلن فعلی** در همان Location نمایش داده می‌شود.
- فقط پلن‌های سازگار، هم‌معماری و **واقعاً Available در همان Location** در لیست انتخاب نشان داده می‌شوند.
- برای دیدن موجودی لازم نیست سرور خاموش باشد؛ برای اعمال Resize باید سرور خاموش باشد.
- هنگام تأیید می‌توانید انتخاب کنید:
  - فقط CPU/RAM تغییر کند و Disk دست‌نخورده بماند.
  - اگر پلن جدید Disk بزرگ‌تری دارد، Disk هم ارتقا پیدا کند.
- قبل از ارتقای Disk هشدار واضح نمایش داده می‌شود؛ افزایش Disk برگشت‌پذیر نیست و بعداً نمی‌توان Disk را کوچک کرد.

## 🌐 Floating IP حرفه‌ای در هر پروژه

از داشبورد پروژه وارد `Floating IP` شوید.

امکانات:

- نمایش همه Floating IPهای پروژه در یک پیام
- ساخت IPv4 یا IPv6
- انتخاب Home Location
- نام‌گذاری IP
- مشاهده سرور متصل
- اتصال به سرور
- انتقال به سرور دیگر
- Unassign / جدا کردن
- حذف IP
- نمایش دستور اضافه‌کردن IP در Linux
- نمایش دستور حذف IP در Linux

Floating IP فقط به سروری نمایش داده می‌شود که Primary IP هم‌نوع داشته باشد.

نمونه دستور IPv4:

```bash
sudo ip addr add 1.2.3.4/32 dev eth0
```

حذف موقت:

```bash
sudo ip addr del 1.2.3.4/32 dev eth0
```

برای ماندگاری پس از reboot باید تنظیم Persistent شبکه سیستم‌عامل انجام شود.

## 🔑 Token Management در Setup

با اجرای همان دستور یک‌خطی و انتخاب `Token Management` این گزینه‌ها در دسترس‌اند:

```text
1) List Hetzner project tokens
2) Add Hetzner project token
3) Change Hetzner project token
4) Remove Hetzner project token
5) Change Telegram Bot Token
6) Change Allowed Telegram User ID
0) Back
```

در List، توکن کامل چاپ نمی‌شود و فقط نسخه Mask شده نمایش داده می‌شود.

بعد از Add / Change / Remove، فایل تنظیمات بروزرسانی و سرویس به‌صورت خودکار Restart می‌شود.

> برای جلوگیری از خراب شدن ربات، حذف آخرین Hetzner Project Token مجاز نیست؛ ابتدا یک Project جدید اضافه کنید و سپس قبلی را حذف کنید.
