# 🤖 ربات خصوصی مدیریت Hetzner در تلگرام

یک پنل سبک و فارسی برای مدیریت **Hetzner Cloud** از داخل تلگرام. این نسخه فقط روی Hetzner تمرکز دارد و Cloudflare به‌طور کامل از پروژه حذف شده است.

## 🚀 نصب یک‌خطی

روی Ubuntu/Debian اجرا کنید:

```bash
bash <(curl -Ls --ipv4 https://raw.githubusercontent.com/0fariid0/hetzner_telegram_bot/main/setup.sh)
```

اسکریپت نصب انگلیسی است و به‌صورت خودکار Python، محیط مجازی، وابستگی‌ها و سرویس `systemd` را آماده می‌کند. در زمان نصب، Telegram Bot Token، شناسه عددی کاربر مجاز و توکن پروژه‌های Hetzner از شما گرفته می‌شود.

> این دستور پس از قرار دادن همین سورس در `0fariid0/hetzner_telegram_bot` روی شاخه `main` مستقیماً قابل استفاده است.

## 🔒 دسترسی کاملاً خصوصی

ربات فقط به **یک Telegram User ID عددی** که هنگام نصب تعیین می‌کنید پاسخ می‌دهد.

- تمام فرمان‌ها برای سایر کاربران نادیده گرفته می‌شوند.
- دکمه‌های مدیریتی فقط برای همان کاربر مجاز قابل استفاده‌اند.
- `/id` نیز فقط برای کاربر مجاز پاسخ می‌دهد.
- محدودسازی بر اساس **User ID** است، نه نام کاربری تلگرام و نه Chat ID گروه.

مقدار مربوطه در `.env` با نام زیر ذخیره می‌شود:

```env
ALLOWED_USER_ID=123456789
```

## 📁 پشتیبانی از چند پروژه Hetzner

هنگام نصب می‌توانید تعداد پروژه‌های Hetzner را مشخص کنید. برای هر پروژه یک نام و یک API Token با سطح **Read/Write** وارد می‌شود.

به این ترتیب می‌توانید مثلاً پروژه‌های زیر را جداگانه از همان ربات مدیریت کنید:

- Production
- Germany
- Finland
- Backup

توکن پروژه‌ها به شکل Base64-encoded JSON داخل `.env` ذخیره می‌شود تا تنظیم چند پروژه بدون اضافه شدن فایل تنظیمات جدید انجام شود.

## ✨ امکانات

### 🖥 مدیریت سرورها

- نمایش سرورهای هر پروژه
- نمایش نام، وضعیت، Primary IPv4، پلن، CPU، RAM، Disk و Location
- نمایش ترافیک خروجی ماه جاری
- روشن کردن سرور
- خاموش کردن امن سرور
- Refresh اطلاعات
- اتصال Primary IPv4 آزاد
- جدا کردن و حذف Primary IPv4 با تأیید نهایی

### ⚙️ تغییر سایز Server

از داخل صفحه هر سرور می‌توانید **تغییر سایز** را انتخاب کنید.

ربات:

- فقط پلن‌های هم‌معماری و سازگار را نمایش می‌دهد.
- قبل از Resize بررسی می‌کند سرور خاموش باشد.
- مشخصات پلن جدید را قبل از اجرا نشان می‌دهد.
- دو انتخاب می‌دهد:
  - تغییر سایز **بدون افزایش Disk**
  - تغییر سایز **همراه افزایش Disk**
- برای افزایش Disk هشدار می‌دهد که کوچک‌کردن دوباره Disk ممکن نیست.

## 🌐 مدیریت حرفه‌ای Floating IP

Floating IP برای هر پروژه به‌صورت مستقل مدیریت می‌شود.

امکانات:

- مشاهده همه Floating IPهای پروژه
- ساخت Floating IPv4
- ساخت Floating IPv6
- انتخاب Home Location هنگام ساخت
- تعیین نام دلخواه برای IP، مثل `panel-prod` یا `project-a-ip`
- اتصال Floating IP به یک سرور
- انتقال Floating IP از یک سرور به سرور دیگر
- جدا کردن Floating IP از سرور
- حذف Floating IP با تأیید
- نمایش نام سروری که IP به آن متصل است
- نمایش دستور لازم برای اضافه‌کردن IP داخل Linux
- نمایش دستور حذف IP از Linux

نمونه دستور IPv4 که ربات پس از اتصال نمایش می‌دهد:

```bash
sudo ip addr add 1.2.3.4/32 dev eth0
```

و برای حذف موقت:

```bash
sudo ip addr del 1.2.3.4/32 dev eth0
```

ربات مشخص می‌کند این دستورات موقت هستند و برای باقی‌ماندن IP بعد از reboot باید تنظیم Persistent متناسب با سیستم‌عامل انجام شود.

## 🚨 هشدار شبانه ترافیک 18 / 19 / 20 TB

ربات هر شب به‌صورت خودکار ترافیک خروجی ماه جاری تمام سرورها در تمام پروژه‌ها را بررسی می‌کند.

آستانه‌های هشدار:

- ⚠️ 18 TB
- 🚨 19 TB
- 🛑 20 TB

اگر یک یا چند سرور وارد محدوده هشدار شده باشند، **فقط یک پیام هشدار در همان روز** برای کاربر مجاز ارسال می‌شود و همه سرورهای درگیر داخل همان پیام قرار می‌گیرند.

در هشدار این اطلاعات نمایش داده می‌شود:

- نام Server
- نام Project
- مصرف ترافیک خروجی
- بالاترین آستانه‌ای که رد شده است
- ترافیک Included گزارش‌شده توسط Hetzner، در صورت وجود
- مقدار باقی‌مانده تا 20 TB

اگر مصرف همچنان بالا باشد، شب بعد یک هشدار جدید ارسال می‌شود؛ بنابراین در هر روز حداکثر یک هشدار دریافت می‌کنید.

تنظیم پیش‌فرض:

```env
BOT_TIMEZONE=Asia/Tehran
TRAFFIC_CHECK_TIME=23:30
```

برای تغییر زمان فقط `.env` را ویرایش و سرویس را Restart کنید.

```bash
systemctl stop hetznerbot

journalctl -u hetznerbot -f
```

## ⚙️ فایل تنظیمات

پس از نصب:

```text
/opt/hetzner-telegram-bot/.env
```

نمونه ساختار:

```env
TELEGRAM_BOT_TOKEN=...
ALLOWED_USER_ID=123456789
HETZNER_PROJECTS_B64=...
BOT_TIMEZONE=Asia/Tehran
TRAFFIC_CHECK_TIME=23:30
STATE_FILE=/opt/hetzner-telegram-bot/.traffic_alert_state.json
```

پس از هر تغییر:

```bash
systemctl restart hetznerbot
```

- Telegram Token و Hetzner API Token را داخل GitHub عمومی قرار ندهید.
- برای هر پروژه Hetzner از API Token با سطح Read/Write استفاده کنید.
- فایل `.env` توسط Installer با دسترسی محدود ساخته می‌شود.
- ربات با یک Linux user جداگانه به نام `hetznerbot` اجرا می‌شود.
